# 🎬 AI Video Toolkit

Professional toolkit for AI video generation workflows.

## 📚 Features

- **Camera Control Database**: Complete reference with 42+ cinematic techniques
- Shot types, angles, movements, and effects
- Search and filter functionality
- Prompt examples for each technique
- Mobile responsive design

## 🚀 Live Demo

Visit the toolkit: [https://albertoperaltag.github.io/ai-video-toolkit/](https://albertoperaltag.github.io/ai-video-toolkit/)

## 📖 What's Included

### Camera Techniques
- **Distance & Size** (10 shots): EWS, Wide Shot, Full Shot, MLS, Cowboy, Medium Shot, MCU, Close-Up, ECU, Macro
- **Angles** (10 types): Eye-Level, Low/High Angle, Bird's Eye, Worm's Eye, Dutch Angle, OTS, POV, Selfie, Ground Level
- **Basic Moves** (6 movements): Static, Pan, Tilt, Zoom In/Out, Pedestal
- **Advanced Physical** (5 techniques): Dolly In/Out, Truck, Orbit, Crane
- **Cinematic & AI** (11 effects): Dolly Zoom, Crash Zoom, FPV Drone, Bullet Time, Handheld, Roll, Rack Focus, and more
